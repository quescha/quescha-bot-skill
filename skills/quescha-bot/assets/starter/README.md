# Рабочая папка бота

- `bot.json` — редактируемый экспорт Quescha из 18 полей.
- `bot.config.json` — название, имя архива и пути проверок.
- `tests.js` — смысловые проверки именно этого бота.
- `mutations.js` — намеренные поломки; каждая должна ловиться валидатором или тестом.
- `upload/` — файлы, которые нужно включить в архив.

Полный цикл:

```bash
node /путь/к/quescha-bot/bin/quescha-bot.js build .
```

На выходе: `dist/coffee-guide.zip`. Загрузите ZIP через «Настройки аккаунта» → «Экспорт / Импорт» в Quescha и проверьте диалог в подключённом канале.
